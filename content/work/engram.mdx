learned: I started Engram thinking the interesting problem was the search algorithm. It took me an embarrassingly long time to realize the architecture was the actual product. A hundred containers running continuously would be financially DOA for a part-time student. But a hundred containers that can be frozen and restored on demand? Now your biggest cost is storage, not compute. Checkpoint and restore mechanics were essential complexity to give Engram any shot at working.

A distributed, privacy-first search engine built as a platform of modular Docker containers. Each container owns one concern — crawling, indexing, ranking — and communicates through reactive streams.
