## Is there a difference between remembering something and truly knowing it?

I think so. "Deep recall" is my term for a specific quality of memory where 
an idea is structurally fluent. I can reach for it without mnemonics, without 
cross-referencing a validation idea to make sure I've got it right, without calculating 
my way back to it. It just holds.

Shallow recall requires scaffolding to access or verify. Deep recall is load-bearing 
on its own. It's solid enough to build on mid-thought, mid-conversation or as a design component.

## What makes a memory feel load-bearing?

My working hypothesis is that it's about connections. An idea that is tied into many 
other ideas becomes easier to reach because there are more roads to it. I've read that neurons which 
fire together wire together. I interpret that to mean that if I consistently encounter an idea alongside related 
concepts, those associations might become part of how I access it.

> Hebb, D. O. (1949). *The organization of behavior: A neuropsychological theory*.

## What distinguishes an associative memory network from a collection of isolated facts?

I don't know if everyone thinks this way, but in my mind, I have to exert effort to identify and
pay attention to the ways that ideas relate to each other. Without that effort, a collection of
facts aren't really a collection -- they aren't a unit. It's easy for an element or two of that
collection to disappear without my noticing at all. 

An associative network, however, is a map. Each idea points to a next one in one way or another. 
Retrieving one idea creates pressure on adjacent ideas, so they surface too. I'm sure there are more
academic sources anchoring this idea. I can't be the first person to intuit this.

## Is a flashcard the right unit for building associative memory?

No clue if a "right unit" is even worth thinking about. But it's an easy tool to access as a curious
programmer. I don't have academic resources or credibiity, but flashcards must be such a widely-used
tool for shaping memory because they work. Whether the flashcard format can build the kind of terrain I'm interested
in, or whether it only builds isolated retrieval paths, is an open question. And probably beyond the 
scope of my little project.

## Does my flashcard app even really test the kind of memory I'm interested in?

I should come back to this question. I didn't start programming to actually quantify how well the mental
model translates to the real works, but I don't think it'd be hard to quantify. (Famous last words.) I 
think I'll know personally if it works when I struggle less to recall ideas I understand. But I would really
enjoy having objective proof that structured reinforcement can deliberately mold the shape of conceptual
associations.
